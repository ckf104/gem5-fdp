**对话1**
ckpt.patch 中包含的修改是一位学长的旧的 gem5 版本上的实现，它截取程序某一段的运行记录，得到 checkpoint，后续可以单独运行该 checkpoint 而不需要运行完整的程序。它的具体使用和实现方法见 README.md。除了 patch 中包含的修改，还新增了 5 个文件，它们在 /home/ckf104/bishe/gem5-ckpt 目录中
```
        src/sim/ckpt_collect.cc
        src/sim/ckpt_collect.hh
        src/sim/ckpt_saveFLoads.cc
        src/sim/ckptinfo.cc
        src/sim/ckptinfo.hh
        src/sim/fastlz.cc
        src/sim/fastlz.hh
```

该实现核心的想法是记录截取的 checkpoint 起始的寄存器状态，运行过程中使用的地址段和第一次 load 得到的数据，以及 syscall 返回的数据，这样保证以后可以从 checkpoint 处开始执行。

总的来说，这些修改代码可以归为以下三类
* 制作 checkpoint，这部分是最核心的代码，包括 settingsfile 中的 readckpt 字段以及后续和该字段相关的代码
* 支持 champsim trace 相关的代码
* README_Support_Readckpt.md 文档中指示的修改，它用来让 gem5 能够加载 checkpoint 并支持特定的拓展指令

**对话2**
